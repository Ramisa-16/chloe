## ✨ Features

- **Distinct Persona** — consistent character identity across conversations
- **Multi-turn Memory** — tracks conversation history for context
- **Adaptable Tone** — adjusts style based on user interaction
- **Domain Scoped** — focused expertise area

## 🚀 Getting Started

```bash
git clone https://github.com/Ramisa-16/chloe.git
cd chloe
pip install -r requirements.txt
export OPENAI_API_KEY="your-key"
python main.py
```
